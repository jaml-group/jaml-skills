# common.align

`Styles.align.*` — flexbox alignment for individual children.

---

## Variants

### `align`

Sets alignment properties for flex/grid children.

Arguments, defaults and options: [generated catalog](../../API/index.md#find-any-exported-path). Catalog lookup: `style align`.

```json jaml-playground
[
    {
        "type": "label",
        "cap": "Centered",
        "styles": ["align(alignSelf:center)"]
    }
]
```
