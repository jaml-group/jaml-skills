# common.mask

`Styles.mask.*` -- CSS mask-image properties.

---

## Variants

### `mask`

Applies a CSS mask image to an element.

Arguments, defaults and options: [generated catalog](../../API/index.md#find-any-exported-path). Catalog lookup: `style mask`.

```json jaml-playground
[
    {
        "type": "label",
        "cap": "Masked",
        "styles": ["mask(mask:linear-gradient(black, transparent))"]
    }
]
```

### `gradient`

Applies a gradient mask to the element.

Arguments, defaults and options: [generated catalog](../../API/index.md#find-any-exported-path). Catalog lookup: `style mask.gradient`.
