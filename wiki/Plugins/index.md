# Plugin reference

Choose the owning topic, then read the entry’s arguments, prerequisites and cleanup requirements.

These descriptions help selection; they do not replace argument contracts. For a control, input or metric, select its [native element](../JAM-UI/JAM-UI.md) first. For an ambiguous purpose, read the relevant [chooser topic](../choosing-native-capabilities.md). A known fitting capability can go directly to its guide.

- [composable-plugins](composable-plugins.md) — Configuration-driven dashboard composition; requires a configuration and router.
- [event](event.md) — Publish scroll progress and active section through the messenger.
- [follow-scroll](follow-scroll.md) — Follow growing content while preserving reader-controlled pause/resume.
- [i18n](i18n.md) — Load translation dictionaries for existing localization.
- [interact-plugins](interact-plugins.md) — Drag data, accept drops and other explicit interaction engines; free positioning starts with styles.
- [navigation](navigation.md) — Previous/next controls backed by an existing live collection owner.
- [observe](observe.md) — Observe direct children or viewport intersection without owning the UI.
- [popup](popup.md) — Attach contextual menus or tips; check trigger, focus and cleanup.
- [router-plugins](router-plugins.md) — URL-driven root and nested content outlets.
- [shortcut](shortcut.md) — Application-defined hover actions; not keyboard-shortcut registration.
- [show-more](show-more.md) — Reveal another batch of existing native rows.
- [subRouter](subRouter.md) — A nested outlet beneath the parent or global router.
