# Generated catalog provenance

The pinned public authoring catalog and shared reader are exported from `@jam/jam-ui`; `artifact.json` records the framework label, catalog/schema digests, file hashes and the publisher's MIT license declaration. The reader includes a generated copy of the existing synchronous i18n engine and shared metadata logic. It is a narrow tooling dependency, not the complete framework runtime.

Authored documentation, examples and consumer tooling in this repository remain under its MIT license. The publisher's authoritative [MIT notice](LICENSE), including its copyright attribution, is included unchanged and covered by the pinned export's file checksums.

Generated files are kept byte-for-byte so their identities match editor/tooling artifacts. Application code, private source locations and registries are excluded from the public catalog envelope.
